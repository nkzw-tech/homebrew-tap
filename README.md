# Homebrew Tap

Homebrew tap for Codiff and Notes.

## Install

```sh
brew install --cask nkzw-tech/tap/codiff
brew install --cask nkzw-tech/tap/notes
```

Or tap the repository first:

```sh
brew tap nkzw-tech/tap
brew install --cask codiff
brew install --cask nkzw-tech/tap/notes
```

Codiff is published from https://github.com/nkzw-tech/codiff/releases.

Notes requires macOS 13 or newer on Apple Silicon and is published from https://github.com/nkzw-tech/notes/releases.
